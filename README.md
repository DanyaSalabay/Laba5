# Задание 
Разработать консольное приложение с дружественным интерфейсом с возможностью выбора заданий. Приложение должно выполнять следующие функции:
1. Чтение базы данных из excel файла.
2. Просмотр базы данных.
3. Удаление элементов (по ключу).
4. Добавление элементов.
5. Реализация 4 запросов LINQ.
6. Сохранение изменений в excel файле.

База данных состоит из 3 связанных таблиц (листов Excel): **«Движение товаров»**, **«Товар»** и **«Магазин»**.

## Задача 1

### Текст задачи
Разработать приложение для работы с базой данных магазинов. Предметная область: движение товаров. Сущности: `Shop` (Магазин), `Product` (Товар), `Movement` (Движение товаров).

### Алгоритм решения

**Архитектура проекта:**
Проект разделен на слои для соблюдения принципов чистого кода:
* `Models.cs` — содержит классы сущностей (`Shop`, `Product`, `Movement`). Поля приватные (с `_`), доступ через свойства. Перегружен метод `ToString()`.
* `DataHelper.cs` — вспомогательный класс для работы с файлами (чтение/запись Excel, добавление, удаление). Используются библиотеки `ExcelDataReader` и `ClosedXML`.
* `Queries.cs` — класс, содержащий бизнес-логику (4 LINQ-запроса).
* `Program.cs` — точка входа, реализует консольное меню.


**Пункт 1. Чтение базы данных из Excel файла**

* **Алгоритм:** При запуске программы в методе Main создается экземпляр класса DataHelper, которому передается путь к файлу. Затем вызывается метод LoadData().
Внутри него сначала выполняется проверка на существование файла (File.Exists). Если файл на месте, с помощью библиотеки ExcelDataReader открывается поток чтения. Программа считывает все листы (AsDataSet()) и последовательно передает их в методы LoadShops, LoadProducts и LoadMovements.
В этих методах происходит обход строк таблицы, пропуск заголовков и пустых строк (DBNull), а затем данные конвертируются в соответствующие типы (например, Convert.ToInt32 или Convert.ToDateTime) и сохраняются в списки _shops, _products и _movements.

**Пункт 3. Удаление элементов (по ключу)**
* **Алгоритм:** При выборе пункта «2» вызывается метод `DeleteRecord()`. Пользователь вводит ID операции. В `DataHelper` вызывается метод `RemoveMovement(id)`, который с помощью LINQ-оператора `FirstOrDefault()` находит элемент в списке `_movements`. Если элемент найден, он удаляется, а метод возвращает `true`. Если ID не существует, возвращается `false`, и программа выводит сообщение об ошибке.

**Пункт 4. Добавление элементов**
* **Алгоритм:** При выборе пункта «3» вызывается метод `AddNewMovement()`. Реализована защита от некорректного ввода:
  1. Ввод ID: цикл `while` проверяет, является ли ввод числом (`int.TryParse`), и проверяет уникальность ID через `Any()`.
  2. Ввод ID магазина: проверяется наличие в таблице `Shops`.
  3. Ввод артикула: проверяется наличие в таблице `Products`.
  4. После валидации создается объект `Movement`, добавляется через `AddMovement()`, и список автоматически сортируется по ID с помощью `OrderBy()`.

**Пункт 5-1. LINQ-запрос 1 (1 таблица, одно значение)**
* **Алгоритм:** В классе `Queries` вызывается метод `Query1()`. Запрос обращается только к списку `_movements`. С помощью синтаксиса `from ... where ... select` отбираются строки с типом «Продажа», после чего агрегатная функция `.Sum()` немедленно вычисляет общее количество проданных упаковок.

**Пункт 5-2. LINQ-запрос 2 (2 таблицы, перечень)**
* **Алгоритм:** В классе `Queries` вызывается метод `Query2()`. Запрос использует `join` для объединения таблиц `Movements` и `Shops` по ключу `ShopId`. Фильтруются только продажи. Результат группируется по адресу магазина (`group by`), суммируется (`Sum`), сортируется по убыванию (`OrderByDescending`) и ограничивается 5 строками (`.Take(5)`). Выводится ТОП-5 магазинов.

**Пункт 5-3. LINQ-запрос 3 (3 таблицы, перечень)**
* **Алгоритм:** В классе `Queries` вызывается метод `Query3()`. Запрос объединяет три таблицы: `Movements`, `Shops` и `Products` с помощью двух `join`. Отбираются записи, где район магазина — «Центральный». В результат (анонимный тип) проецируются название товара, адрес магазина и количество. Выводится перечень поступлений и продаж.

**Пункт 5-4. LINQ-запрос 4 (3 таблицы, одно значение)**
* **Алгоритм:** В классе `Queries` вызывается метод `Query4()`. Объединяются три таблицы (`Movements`, `Shops` и `Products`). Фильтр: адрес магазина содержит «Гагарина», дата операции находится в диапазоне с 1 по 10 июля, тип операции — «Продажа», а наименование товара содержит «Гель для душа». В `select` берется количество упаковок (`m.Quantity`), после чего функция `.Sum()` мгновенно суммирует все значения, возвращая общее число.

**Пункт 6. Сохранение изменений в Excel**
* **Алгоритм:** При выборе пункта «8» вызывается `SaveData()` в `DataHelper`. С помощью библиотеки `ClosedXML` открывается файл `.xlsx`. Старые данные со второй строки листа удаляются (`Rows.Delete`). Затем в цикле `for` перебирается обновленный список `_movements` и данные записываются в соответствующие ячейки. Файл сохраняется методом `workbook.Save()`.
